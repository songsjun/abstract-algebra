# 抽象代数学习室

一套中文抽象代数入门课程，按 David S. Dummit 和 Richard M. Foote 的《Abstract Algebra》第三版组织。

- 97 节课包括预备知识、19 章和两篇附录。48 节列入基础路线，其余为进阶导读。
- 每节有概念讲解、分步例题与单选练习。146 道课内题中有 29 道教材改编题，标有原题出处。
- 综合测验共 20 题，答对 12 题达到站内基础目标。分数尚未与实际课程考试校准。
- 学习记录保存在当前浏览器和网址的本地存储。

## 本地运行

从仓库根目录运行以下命令，打开 [本地学习室](http://127.0.0.1:8732/)。

```sh
python3 -m http.server 8732 --bind 127.0.0.1
```

也可以直接打开 `index.html`，无须安装依赖或构建。

## 课程与发布

`course.js` 定义课程目录，三个 `lessons-*.js` 文件包含课内内容，`assessment.js` 包含综合测验。GitHub Pages 从 `main` 分支根目录发布静态文件。
